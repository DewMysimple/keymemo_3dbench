# ADR-001 工作台与网页记忆路由

## 决策

Blender 工作台和网页项目共用 Verminoble 的 `main` 分支与提交历史，不创建新的 Git 支线、独立仓库或子模块。记忆按任务范围分流：网页任务写主线 `wiki_memory/`，Blender 任务写本地 `blender_scenebench/wiki_memory/`，混合任务分别写入两边。

## 结果

本地记忆承载场景结构、对象和材质契约、Blender 资源路径、构建/修复/验证/渲染流程及创作日志。主线记忆只承载网页资源事实、运行时事实和工作台边界，不重复存放 Blender 实现细节。
