# Blender 工作台当前约束

- 主文件名保持 `blender/GwayLoo_Scene_5_0.blend`；不得无授权重命名 Blender 数据块、对象、材质或动画。
- `full` 是唯一完整基准版本；版本准备不得覆盖来源文件，派生版本必须是独立 `.blend`。
- 版本准备默认只预演；必须显式使用 `--create` 才能写入目标。`no-animation` 已获授权并固定在第 3586 帧，删除全部非相机动画，完整版本不能被覆盖。
- `source_snapshot/`、`generated/`、`.blend1` 和 `.blend2` 按工作台 `.gitignore` 保持本地忽略；跟踪的交付文件不能重新依赖这些目录。
- 外部图像、视频和字体必须指向仓库跟踪的 `public/.../xp` 资源，或明确打包进 `.blend`。
- 清单生成默认只校验仓库内 `source_snapshot/` 与 `public/.../xp`；私有参考目录必须通过 `--reference-root` 或 `GWAYLOO_REFERENCE_XP` 显式提供。
- 复制到不同目录后必须重新计算资源相对路径；资源、结构或独立性验证失败时不能标记版本可用。
- 构建脚本不得修改 Blender 全局用户偏好；工作区状态必须由项目文件本身保存。
- 工作台不参与网页构建运行时；网页代码不得引用 `blender_scenebench/`。
- Blender-only 结论写入本地记忆；网页-only 结论写入主线记忆；混合任务两边分别记录。
- 项目任务完成后只创建本地 Git commit，不执行 `git push`，也不自动创建新分支。
