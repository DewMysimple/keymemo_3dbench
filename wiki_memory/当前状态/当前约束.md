# keymemo_3dbench 当前约束

- 主文件保持 `blender/GwayLoo_Scene_5_0.blend`；不得无授权重命名 Blender
  数据块、对象、材质或动画。
- `full` 是唯一完整基准；派生版本必须是独立 `.blend`，不得覆盖来源文件。
- 外部图像、视频和字体必须使用仓库内 `source_snapshot/` 的相对路径，或明确
  打包进 `.blend`；不能依赖 `Verminoble`。
- `source_snapshot/` 纳入 Git；`generated/`、渲染输出、`.blend1` 和 `.blend2`
  保持忽略。
- 三个超大原始文件只保留本地，必须与 `manifests/local_assets_manifest.json`
  中的大小和 SHA-256 一致，不能使用 Git LFS 或加入远程。
- 模型转换默认保留几何、材质、贴图、UV、顶点组、骨骼、父子关系、修改器、
  约束、形态键、动作/NLA、时间轴、相机、灯光和自定义属性；简化必须有明确授权。
- 构建脚本不得修改 Blender 全局用户偏好；工作区状态由项目文件保存。
- 本工程与 `Verminoble` 完全分离；历史日志可提及旧路径，但活动脚本不能引用旧路径。
- Git 默认使用 `main`；本次迁移按用户授权设置远程并推送，后续任务仍遵循用户明确授权。
