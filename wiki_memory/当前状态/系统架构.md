# keymemo_3dbench 系统架构

| 区域 | 职责 |
| --- | --- |
| `scenes/GwayLoo/` | GwayLoo 主文件、完整基准和派生版本 |
| `models/<asset>/` | 按模型分区的源素材、模型场景、元数据和历史归档 |
| `runtime/source_snapshot/` | 纳入仓库的可复现运行资源快照 |
| `tools/` | 资源准备、清单、场景构建、修复、验证和渲染 |
| `manifests/` | 资产、场景、版本及本地大文件清单 |
| `reports/` | 构建、验证、渲染和迁移报告 |
| `scenes/GwayLoo/versions/<version-id>/` | 派生 Blender 文件、报告和生成输出 |
| `generated/` | 本地转换、缓存和渲染产物，不进入 Git |
| `wiki_memory/` | 本工程的 Blender 专属工程记忆 |

本仓库不包含网页运行时。所有脚本从根目录计算路径；任何需要运行资源的
`.blend` 都应解析到本仓库的 `runtime/source_snapshot/` 或使用嵌入数据。

## 场景入口

- `ARTIST_EDIT` 是主文件的日常可编辑入口。
- `WEB_ANIMATION` 保存完整网页来源时间线。
- `SOURCE_REFERENCE` 保存隔离的源 GLTF 镜像。
- 六个桌面与六个移动景观场景提供视频层入口。

## 版本入口

`full` 对应 `scenes/GwayLoo/full/GwayLoo_Scene_5_0.blend`，派生版本从它创建独立副本。
`no-animation` 在第 3586 帧固化非相机对象并保留相机动作。它同时采用
`self-contained-no-video-no-external-font` 资产策略：保留 12 个景观场景入口，删除其
24 个 MP4 图像数据块，使用 Blender 内置字体，并把其余 8 张图像嵌入文件。
