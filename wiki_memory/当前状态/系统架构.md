# Blender 工作台系统架构

| 区域 | 职责 |
| --- | --- |
| `blender/` | 跟踪的 Blender 5.0 主文件和稳定交付入口 |
| `tools/` | 资源准备、清单提取、场景构建、修复、验证和渲染 |
| `manifests/` | 资产与场景结构清单 |
| `manifests/version_registry.json` | 完整版本与派生版本注册表 |
| `reports/` | 构建、验证、渲染和边界报告 |
| `versions/<version-id>/` | 派生版本的独立 Blender 文件、报告和生成输出；当前仅预留规范 |
| `source_snapshot/` | 本地忽略的原始运行资源副本 |
| `generated/` | 本地忽略的转换、缓存、备份和渲染产物 |
| `wiki_memory/` | Blender 专属工程记忆 |

工作台位于网页 `src/` 和 `public/` 之外。主 `.blend` 的外部运行资源通过相对路径指向仓库跟踪的 `public/.../xp` 资产，必要的生成 Ground 图集和字体嵌入文件；因此普通 Git 克隆不依赖被忽略的快照目录。

## 场景入口

- `ARTIST_EDIT` 是默认可编辑入口。
- `WEB_ANIMATION` 保存完整网页来源时间线。
- `SOURCE_REFERENCE` 保存隔离的源镜像。
- 六个桌面和六个移动场景保存视频景观入口。

## 版本入口

`full` 对应当前 `blender/Verminoble_Scene_Mirror_5_0.blend`，是所有衍生版本的来源。版本准备工具从来源文件重新保存到目标文件，以便按目标位置重算相对资源路径；不会使用 Blender 链接库共享可变数据。当前只登记 `no-animation` 为计划版本，不创建目标文件。
