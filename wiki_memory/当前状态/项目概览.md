# keymemo_3dbench 项目概览

`keymemo_3dbench` 是独立的 Blender 5.0 模型与场景工作台。仓库根目录就是
工作台根目录，源自 `Verminoble/blender_scenebench` 的历史提取；原目录保留
为本地备份，但新工程不依赖它的路径、运行时或 Git 关系。

主文件为 `scenes/GwayLoo/full/GwayLoo_Scene_5_0.blend`，是 `full` 完整基准版本。
`scenes/GwayLoo/versions/no-animation/` 保存独立的去除非相机动画版本。该派生文件已
移除 24 个视频引用和外部 Canela 字体，六个标题改用 Blender 内置字体，其余 8 张
图像全部嵌入 `.blend`，因此打开和渲染主场景不依赖外部资产。
模型基准、构建脚本、报告、清单以及 Blender 工程记忆全部位于本仓库内。
`models/othermodel/` 另存一组按类别整理的 OBJ 展示文件：61 个 OBJ 已分成 7 个类别，
每类一个 `.blend`，模型按源文件名自然排序并配有展示摄影机与标签。

主 `.blend` 的外部运行资源已重定位到 `runtime/source_snapshot/assets/`；生成缓存不进
Git。三个超过 GitHub 100 MB 限制的原始文件仅保留在本机，并由
`manifests/local_assets_manifest.json` 记录。
