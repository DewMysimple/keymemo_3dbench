# Blender 工作台项目概览

`blender_scenebench/` 是 Verminoble 主线中的本地 Blender 5.0 场景工作台。它与网页代码在同一个 `main` 工程中同步开发，但不作为 Vite 正式运行时目录，也不创建独立 Git 支线。

主文件为 `blender/GwayLoo_Scene_5_0.blend`，是当前唯一完整基准版本。版本注册表位于 `manifests/version_registry.json`；`versions/no-animation/` 已保存从完整版本生成的独立静止版本，后续派生版本继续使用独立 `.blend`、报告和生成输出。Blender 专属构建、验证、资产和创作记忆都在本地 `wiki_memory/` 维护；网页资源和运行时边界仍以主线记忆为准。
