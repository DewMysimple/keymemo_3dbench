# keymemo_3dbench 已知问题

- Blender 渲染器与网页 WebGL 的水彩、SDF、纸张和 LUT 后处理不存在逐像素等价保证，
  仍需逐帧校准。
- 三个超大原始模型文件不在远程仓库；在全新克隆中需按本地资产清单从原始备份补齐。
- `generated/` 渲染和转换缓存不随 Git 迁移，需要在本机按脚本重新生成。
- HDRI、透明材质和实时预览的观感受 Blender 版本、视图变换和渲染器设置影响，不能
  仅以工作台截图作为最终渲染等价证明。
