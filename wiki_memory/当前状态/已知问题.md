# Blender 工作台已知问题

- Blender 渲染器与网页 WebGL 水彩、SDF、纸张和 LUT 后处理不存在逐像素等价保证，仍需逐帧校准。
- 原始媒体、字体、模型、音频和画布内英文仍受主线本地实验与授权边界约束。
- 当前验证保证项目克隆可解析跟踪的 `public/.../xp` 资源，但不把外部公共资源变成完全自包含的单文件交付。
