# 修正蝴蝶头部摄像机正面跟踪视角

## 问题

此前的测试把摄像机方向锁在世界坐标，只让位置跟随头部。蝴蝶转向后会在画面中斜置，地面也可能切入画面，不符合用户提供的正面展开参考图。

## 修正

保留头部绑定父级链，让 `CAMERA_HEAD_FOLLOW` 的位置继续随 `CAMERA_HEAD_ANCHOR` 移动；同时在摄像机上添加 `CAMERA_HEAD_TRACK_TO`，使用 `DAMPED_TRACK` 持续对准 `CAMERA_HEAD_LOOK_TARGET`。初始镜头改为自上而下正面展开视角，使用正交相机和统一构图比例。这样摄像机在动画中会不断变化旋转，对准蝴蝶，同时保持相对蝴蝶的正面第三人称视角。

## 影响范围

仅更新：

- `blender/follow_path/head_camera/BUTTERFLY_FLAP_FAST_FOLLOW_PATH_1_HEAD_CAMERA.blend`
- `blender/follow_path/head_camera/BUTTERFLY_FLAP_FAST_FOLLOW_PATH_2_HEAD_CAMERA.blend`
- 头部摄像机构建脚本、更新脚本、验证器和 Butterfly README

两个原始 Follow Path 文件保持不变，模型、翅膀、材质、UV、动画、运动路径、打包贴图和 C4D 原始数据不改动。

## 验证

中间帧渲染确认两个副本保持正面展开构图。验证器检查摄像机位置相对头部锚点偏移稳定、摄像机旋转在动画帧之间变化、DAMPED_TRACK 目标正确、摄像机始终对准 `CAMERA_HEAD_LOOK_TARGET`，并继续检查原有 11 个正式 Blender 文件的数据完整性。

## 待确认长期记忆

- Butterfly 头部镜头的目标行为是“头部位置跟随 + 持续旋转对准蝴蝶”，不是世界坐标方向锁定。
- 正面展开镜头使用 `CAMERA_HEAD_TRACK_TO` 的 `DAMPED_TRACK` 约束；手动调整时必须保留头部父级和该约束。
