# 2026-08-22｜三维场景工作区与 Blender 镜像

## 目标

- 在正式网页之外建立本地三维二创工作区。
- 无损复制网页沉浸体验使用的模型、纹理、视频、音频、字体和运行时事实。
- 使用 Blender 5.0.0 生成原始镜像与可编辑重建共存的主文件。
- 将根级记忆目录从 `工程记忆/` 重命名为 `wiki_memory/`，不改变其子目录结构。

## 实施结果

- 新增 `scene_workbench/`，位于 `src/` 和 `public/` 之外，正式运行时不引用该目录。
- `source_snapshot/` 保存 53 个完整 `xp` 资产、23 个字体和 11 个运行时/配置文件；全部 XP 副本与当前 `public` 来源 SHA-256 一致。
- 与只读 `网页(1)` 对照时仅发现四个 UTF-8 文本文件的 CRLF/LF 差异，归一化内容一致；只读目录未被修改。
- KTX2 Ground 图集通过 Khronos KTX-Software 4.4.2 无损转码为 RGBA8 PNG；Canela WOFF 转为 Blender 可加载的本地 TTF，原文件均保留。
- 生成 `Verminoble_Scene_Mirror_5_0.blend`：13 个 Blender Scene、27 个原始网格、26 个可编辑水彩图层、六个热点、一个可编辑动画相机和十二组桌面/移动视频场景。
- atlas、mask、UV 矩形和 1.25 秒图层显隐时序进入可编辑节点；SDF、纸张、噪声和 LUT 作为明确标注的源输入保留，不伪装成跨渲染器逐像素等价。
- `GROUND_AND_PAPER` 默认不参与主场景渲染，因为原 WebGL 运行时隐藏 GLB Ground 并使用自定义着色管线。
- 生成九张 Blender 验证渲染：主时间线开头/中段/结尾和六个桌面视频场景首帧。

## Git 与隔离

- 跟踪 README、清单、报告和重建/验证脚本。
- 忽略原素材副本、`.blend`、转换文件、工具缓存和渲染输出。
- ESLint 全局忽略本地 source snapshot、生成缓存和 Blender 输出，防止第三方压缩脚本被误当作正式源码检查。
- 未创建 Git 提交，未推送远程。

## 验证

- Blender 5.0.0 无界面打开与验证通过：27 个源网格、26 个可编辑图层、六个热点、十二个视频场景，28 个外部媒体路径均有效且为相对路径。
- 资产清单记录 87 个源快照文件和 SHA-256。
- Blender 主文件与九张验证图均实际生成。
- `lint`、`typecheck`、11 个单元测试、55 项资产检查、生产构建和 10 个桌面/移动 E2E 用例全部通过。
- 记忆索引刷新和 37 个 Markdown 页面体检通过；E2E 临时服务已停止。

## 边界与下一步

- Blender 文件完整镜像场景数据、相机、动画、图层、时间与源资源，但不声明 EEVEE/Cycles 与自定义 WebGL GLSL 逐像素一致。
- 后续原创替换应在 `EDITABLE_WATERCOLOR`、`GROUND_AND_PAPER` 和各 `LANDSCAPE_*` Scene 中进行，再经正式资源迁移流程接回网页。
