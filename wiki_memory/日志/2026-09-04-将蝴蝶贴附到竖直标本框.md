# 将蝴蝶贴附到竖直标本框

## 目标

修改 Butterfly 的两个 `wing_flap_only` 场景：删除灯光，把标本框 GLB 导入为竖直落脚面，并将蝴蝶贴在框内，身体沿世界 Z 轴且位于中心线；同时整理旧展示地面、集合与整体控制原点。

## 结果

- 两份场景均删除4个摄影灯光对象和灯光数据块，同时删除已被标本框取代的水平展示台。
- 将用户提供的 `specimen-frame.glb` 原样复制到 `models/SpecimenFrame/source/specimen-frame.glb`，再导入 `ARTIST_EDIT`；框保留外框与内板两个材质槽，不依赖机器外部绝对路径。
- 标本框位于 YZ 平面，正面为 `X=0.21`；蝴蝶机身腹面的最近点位于 `X=0.212`，只保留约 `0.002` 防穿插间隙，形成实际模型接触关系。
- 撤销框法向 `0.005` 非等比压缩，恢复根节点等比缩放 `(1, 1, 1)`；完整动画的框法向范围为 `X=0.2120–4.0532`，深度约 `3.8412`，侧面和斜视均可辨认原生三维结构。
- 左右翅膀分别增加恒定的朝外安装角偏移，扇动范围改为左翅 `[-2.7858, -0.3558]`、右翅 `[0.3558, 2.7858]` 弧度；关键帧帧号、数量与相对扇动量保持来源 Action 一致，1–91 帧均不穿入框体。
- 蝴蝶身体主轴沿世界 Z，身体中心对齐 `Y=0`；全部动画帧均处于 `7.1 × 7.1` 内芯区域。
- `DISPLAY_Butterfly_Master_ROOT` 原点设在框面中心，作为整体摆放控制；框与相机分别归入 `MODEL_SpecimenFrame_落脚框` 和 `CAMERAS_Butterfly_构图相机`。
- `SOURCE_REFERENCE` 保持源对象、源 Action 与变换不变，不链接标本框；两个扇翅 Action 的相对变化保持对应 Follow Path 来源。

## 构建与验证

- 新增 `tools/butterfly_frame_attachment.py`，并接入原有构建器与专用验证器，防止后续重建恢复旧灯光、旧地面或悬空姿态。
- 构建器改为先保存到 `generated/` 临时文件再原子替换正式文件，正式目录不再产生 `.blend1/.blend2`；本次生成的两份自动 `.blend1` 已删除，受控旧版备份保留在忽略目录。
- 保存后重新打开两份 `.blend`，重新计算全部 91 帧包围盒；灯光数、框材质槽、身体方向、中心线、机身接触、原生三维深度、翅膀不穿框、内芯投影边界和源动画均验证通过。
- 两份正式文件分别渲染第 1、45、91 帧正视图，以及第45帧侧视和斜视；第1帧为翅膀朝外闭合姿态，第45帧为完整展开姿态，侧视确认机身贴框且翅膀向框外伸展。

## 边界

- “贴在框上”由机身腹面与框面形成几何接触实现，不再通过压扁整个蝴蝶伪造；翅膀仍是源生模型中的贴图薄翼网格，机身保持有体积的三维网格。
- Master 与两个 Follow Path 来源文件未修改。
