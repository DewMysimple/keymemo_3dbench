# 2026-08-23｜Blender 界面语言诊断

## 目标

解释 `scene_workbench/blender/Verminoble_Scene_Mirror_5_0.blend` 打开后仍显示英文界面的原因。

## 确认事实

- `scene_workbench/README.md` 和 `scene_workbench/tools/build_blender_scene.py` 明确规定：构建脚本不修改、不保存 Blender 用户偏好；界面语言跟随本机安装设置。
- 构建命令使用 `--factory-startup`，后台生成时读取 Blender 工厂偏好；工厂偏好实测为 `en_US`。
- 直接打开目标 `.blend` 的后台实测显示本机用户偏好为 `language=zh_HANS`，但 `use_translate_interface=False`、`use_translate_tooltips=True`。语言区域值为中文并不会单独启用 Blender 菜单翻译。
- `.blend` 内保存了场景、对象、材质、动画和工作区状态，但没有把 Blender 全局用户偏好作为项目级界面语言保存。
- `EDIT_tree_1`、`WEB_ANIMATION`、`ARTIST_EDIT` 等资产和场景标识是脚本有意保留的 ASCII 英文，不等同于 Blender 内置 UI 语言。

## 结论

英文界面不是场景生成失败，而是项目生成边界与本机偏好共同导致：生成器使用工厂启动隔离构建，且刻意不调用 `save_userpref()`；最终 `.blend` 不能携带“中文界面”覆盖用户偏好。当前机器的中文语言项已选中，但 Blender 的 Interface 翻译开关未启用。

## 待确认长期记忆

- 若后续希望交付“打开即中文 UI”的工作流，应提供安装级 Blender 偏好设置步骤或启动脚本，而不是把偏好写入 `.blend`；是否纳入知识页待用户确认。
