# Blender 参考基准路径可移植化

## 目标

移除 Blender 清单生成器对开发机私有参考目录的硬编码，使 GitHub 克隆项目可以只使用仓库内快照和 `public/.../xp` 资源运行。

## 处理

- `generate_manifests.py` 默认校验仓库快照与当前项目资源。
- 私有参考对照改为 `--reference-root` 或 `GWAYLOO_REFERENCE_XP` 的可选输入。
- 未配置参考目录时，生成报告不写入机器特定绝对路径。
- Blender 工作台场景、版本文件和资源内容未修改。
