# Blender 工作台目录结构统一迁移

## 目标

消除 `blender/` 与 `blender_modelbench/` 的职责混淆，将 GwayLoo 主场景、模型
基准、运行快照和共享基础设施分区管理。

## 结果

- GwayLoo 主文件迁移到 `scenes/GwayLoo/full/`，`no-animation` 迁移到
  `scenes/GwayLoo/versions/no-animation/`，移除了多余的 `blender/` 层。
- Butterfly、SpecimenFrame、兰花、杜鹃花和水分别迁移到 `models/<asset>/`，
  每个模型通过 `source/ → scenes/` 说明来源关系；Butterfly 的
  `archive/legacy/` 保留。
- 运行资源快照迁移到 `runtime/source_snapshot/`；共享 `tools/`、`manifests/`、
  `reports/`、`generated/` 和 `wiki_memory/` 保持在仓库根目录。
- `tools/workbench_paths.py` 成为统一路径入口；迁移工具默认 dry-run，只有
  `--apply` 才执行移动。`tools/rewrite_blend_paths.py` 仅修复资源路径和已知路径
  型属性，Blender 数据结构指纹保持不变。
- 旧的 `blender/`、`blender_modelbench/`、顶层 `versions/` 和旧
  `source_snapshot/` 已搬空并删除，不建立副本、软链接或 junction。

## 验证

- 迁移 262 个文件；三个本地超大原始文件迁移后大小和 SHA-256 不变。
- Blender 5.0 检查 26 个 `.blend`：资源无未解析项，路径不再依赖旧工作台，场景
  结构、对象、材质、动画、场景和父子关系指纹保持不变。
- GwayLoo full/no-animation、Butterfly 验证、SpecimenFrame 几何检查和两套回归
  渲染均通过；版本准备 dry-run、记忆 lint 和 `git diff --check` 完成。
