# 2026-08-23｜生成 Blender 项目中文工作区

## 目标

让 `Verminoble_Scene_Mirror_5_0.blend` 的工作区标签与本机 Blender 启动器一致，保存为中文名称。

## 变更

- 在 `scene_workbench/tools/build_blender_scene.py` 增加确定性的英文到中文工作区映射。
- 工厂启动后将 11 个工作区重命名为 `布局`、`建模`、`雕刻`、`UV编辑`、`纹理绘制`、`着色`、`动画`、`渲染`、`合成`、`几何节点`、`脚本`。
- 默认工作区查找改为中文名称 `布局`；对象、材质、动画和脚本标识继续保持 ASCII 英文。
- 更新 `scene_workbench/README.md`，说明生成项目显式保存中文工作区，但不修改 Blender 全局用户偏好。

## 验证

- 使用 Blender 5.0.0 重新生成目标 `.blend`，命令成功完成。
- 读取目标文件实测工作区列表为中文，当前工作区为 `布局`。
- `validate_blend.py` 通过：26 个可编辑水彩图层、3141 个草叶、12 个视频场景、相对外部路径及 Edit Mode 往返均正常。

## 待确认长期记忆

- 生成器现在对工作区名称采用项目级中文映射；是否将其他可见数据块名称也中文化，仍需单独评估脚本引用和跨环境可移植性。
