# 标本方框立起到 Y-Z 平面并调整物体原点

## 变更

- 基于透明浅紫标本方框的无修改器基础版本，将 `SPECIMEN_OUTER_FRAME` 与 `SPECIMEN_INNER_PANEL` 旋转为 Y-Z 平面姿态，厚度沿 X 轴。
- 两个组件仍保持独立对象，并保留 0 个修改器；没有添加或应用 Bevel、Subdivision Surface。
- 通过平移对象网格数据与设置对象变换，将两个对象的物体原点定位到各自底面中心。
- 相机和灯光调整到立起后的观察方向，透明背景与浅薰衣草紫材质保持不变。

## 验证

- 构建脚本：`blender_scenebench/tools/build_specimen_frame_scene.py`
- 交付文件：`blender_scenebench/blender_modelbench/SpecimenFrame/blender/Specimen_Frame_Transparent.blend`
- 验证报告：`blender_scenebench/reports/specimen-frame-validation.json`
- 关键检查：`standing_in_yz_plane`、`frame_origin_at_bottom_center`、`panel_origin_at_bottom_center`、`no_modifiers`、`all_passed` 均为 `true`。
- 预览：`blender_scenebench/generated/SpecimenFrame/Specimen_Frame_Transparent_preview.png`
