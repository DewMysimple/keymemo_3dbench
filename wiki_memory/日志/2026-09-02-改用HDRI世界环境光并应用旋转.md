# 改用 HDRI 世界环境光并应用旋转

## 变更

- 删除 `KEY_SOFTBOX`、`FILL_LAVENDER`、`RIM_WARM` 三个旧 Area 灯光对象。
- 使用 Blender 自带 `studio.exr` 创建 World 环境纹理，HDRI 已打包进 `.blend`，渲染视图启用场景 World。
- 保持透明渲染背景，因此 HDRI 用于环境照明和高光，不替换透明背景。
- 将外框与紫色主体的立起旋转应用到网格，两个对象的 Rotation 数值归零；父子关系、原点位置和无修改器状态保持不变。

## 验证

- 构建脚本：`blender_scenebench/tools/build_specimen_frame_scene.py`
- 交付文件：`blender_scenebench/blender_modelbench/SpecimenFrame/blender/Specimen_Frame_Transparent.blend`
- 验证报告：`blender_scenebench/reports/specimen-frame-validation.json`
- 关键检查：`hdri_world_environment_loaded`、`old_lights_removed`、`object_rotation_applied`、`panel_parent_follows_frame`、`all_passed` 均为 `true`。
