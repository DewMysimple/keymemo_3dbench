# 制作蝴蝶头部跟随摄像机版本

## 目标

基于两个 Follow Path 独立 Blender 文件制作第三人称头部跟随摄像机副本，原文件不覆盖、不改写。

## 已确认决策

- 输出使用正式工作台根目录下的 `blender_modelbench/Butterfly`。
- 摄像机使用头部后上方的第三人称视角，并设为 `ARTIST_EDIT` 默认摄像机。
- 摄像机完整继承绑定链的移动、旋转和翻滚，不使用稳定地平线的约束。
- FBX 没有独立头部对象，使用展示身体网格头部端的几何参考位置建立锚点。
- 原有 `蝴蝶_英雄相机`、FBX 层级、Action、材质、UV、贴图、OBJ 和 C4D 归档均保留。

## 实施

新增 `tools/build_butterfly_head_camera_variant.py`。脚本逐个从原始 Follow Path `.blend` 读取，拒绝覆盖已有输出或同名备份，然后生成：

- `blender/follow_path/head_camera/BUTTERFLY_FLAP_FAST_FOLLOW_PATH_1_HEAD_CAMERA.blend`
- `blender/follow_path/head_camera/BUTTERFLY_FLAP_FAST_FOLLOW_PATH_2_HEAD_CAMERA.blend`

每个副本新增 `CAMERA_HEAD_ANCHOR`、`CAMERA_HEAD_LOOK_TARGET` 和 `CAMERA_HEAD_FOLLOW`。绑定链为 `CAMERA_HEAD_FOLLOW → CAMERA_HEAD_ANCHOR → 展示身体网格 → 原始 FBX 父级动画链`。摄像机保持局部偏移和旋转，播放动画时随身体父级变换移动；瞄准点作为手动调整和检查的参考对象。

## 验证

- 完整 Butterfly 验证器通过：正式文件 11 个，头部摄像机副本 2 个。
- 两份原始 Follow Path 文件 SHA-256 未变化。
- 两份副本均验证为 `ARTIST_EDIT` 默认场景，默认摄像机为 `CAMERA_HEAD_FOLLOW`。
- 两份副本均验证摄像机父级、身体锚点父级、首帧/中间帧/末帧位置与旋转变化，以及相对锚点距离和局部变换恒定。
- 运动路径仍有 91 个轨迹点；OBJ 身体为 1239 个顶点、1229 个面；4 张图像已打包；C4D 内嵌二进制哈希通过。
- 正式 Blender 目录没有 `.blend1/.blend2`；旧错误入口不存在；`git diff --check` 通过。
- 对两个新默认摄像机各执行了中间帧渲染复核，均能看到蝴蝶及两侧翅膀。

## 交付说明

README 已加入新文件清单、绑定关系及手动调整方法。验证结果写入 `reports/butterfly-validation.json`。原文件编辑路径仍使用 `follow_path` 下的运动空物体和 Action 关键帧；需要调整跟随镜头时，在新副本中移动 `CAMERA_HEAD_ANCHOR` 或调整 `CAMERA_HEAD_FOLLOW`，不要清除其父级关系。
