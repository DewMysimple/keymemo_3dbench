# 2026-08-23｜Blender 主素材 2D 图层视角材质稳定整改

## 目标

修复用户旋转相机到特定角度时，主水彩图层出现灰底、亮度变化或图集边缘异常的问题。确认本轮只处理真实水彩图层材质，不重新引入任何 Blender 阴影卡片。

## 诊断结论

- 灰色镂空区域首先是透明遮罩透出 Blender 视口背景，不是灰色贴图；图集打包不是根因。
- `WC_*` 材质原先把 `SOURCE_ATLAS` 同时接到 Principled Base Color 和 Emission Color。平面网格的单一法线在 Material Preview 的斜视/背面角度下仍会受到漫反射光照影响，造成彩色素材亮度变化。
- 材质使用平滑 `BLENDED` 透明且双面显示，必须保留双面可编辑能力，不能用背面剔除代替修复。
- `EDIT_tree_1` 的源 UV 横向存在约 `1.025` 的轻微越界；没有限制局部 UV 时，图集边缘可能采样到相邻填充区域。
- 对象 Alpha、`WEB_*` 参考节点和已撤回的 `SHADOW_*` 数据不是本问题的视角材质根因。

## 整改

- `scene_workbench/tools/build_blender_scene.py`
  - 水彩卡片继续使用 Blender 5.0 Principled BSDF，但移除漫反射 Base Color 连接，将 Base Color 固定为黑色，仅使用图集 Emission Color 输出平面绘画颜色。
  - 保留双面显示和平滑混合透明，避免素材从背面或编辑角度直接消失。
  - 在 `ATLAS` UV 缩放/偏移前加入 `[0, 1]` 局部 UV 最小/最大钳制，防止轻微源 UV 越界采样相邻图集区域。
  - 保留原有 `texture.jpg`、`texture_mask.jpg`、图集映射、动画和对象 Alpha 逻辑。
- `scene_workbench/tools/validate_blend.py`
  - 增加平滑透明、关闭透明层重叠排序、双面显示、Emission Color 连接和 UV 钳制节点验证。
- `scene_workbench/tools/render_validation.py`
  - 新增树素材正面、斜视、背面三组角度验证。
  - 将用户报告的第 690 帧加入艺术场景回归样本。
- `scene_workbench/README.md`
  - 记录主水彩图层的视角稳定材质规范和新的 29 张回归渲染数量。

## 验证

- 重新生成：`scene_workbench/blender/Verminoble_Scene_Mirror_5_0.blend`。
- Blender 结构验证：通过；26 个水彩图层、26 个动画、23 个程序化草地对象、3141 株草、12 个视频场景、0 个零面积面。
- 阴影边界验证：`SHADOW_APPROXIMATION` 集合和 `SHADOW_*` 对象仍不存在。
- 回归渲染：29 张全部生成，包括第 690 帧以及水彩图层正面/斜视/背面角度。
- 视觉检查：树卡片在三种角度保持彩色；第 690 帧没有出现整块灰底、黑色遮挡或伪造阴影卡片。

## 结果

主水彩图层的颜色不再依赖平面法线的漫反射光照，图集边缘也不会因轻微 UV 越界采样相邻区域。透明镂空区域仍会显示当前视口/场景背景，这是遮罩正常工作的表现，不是素材变灰。

## 待确认长期记忆

- “Blender 5.0 水彩图层使用 Principled Emission Color 作为平面颜色、Base Color 不参与漫反射；局部图集 UV 在重映射前钳制”可提升为场景材质规范。
