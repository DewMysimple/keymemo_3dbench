# 创建蝴蝶仅翅膀扇动版本

## 目标

基于两个 Follow Path 独立文件生成对应的派生版本：保留左右翅膀拍动，去除沿路径产生的整体位移和旋转变化。

## 已确认决策

- 输出放在 `blender_modelbench/Butterfly/blender/wing_flap_only/`，不混入原始 `follow_path/` 文件。
- `ARTIST_EDIT` 只保留两个翅膀对象的动画 Action；路径控制器的位置和旋转固定为第 1 帧，展示运动轨迹也清除。
- `SOURCE_REFERENCE` 保留原始 Follow Path 对象和 Action，作为源数据对照；来源文件不覆盖、不改写。

## 结果

- 生成 `BUTTERFLY_FLAP_FAST_FOLLOW_PATH_1_WING_FLAP_ONLY.blend`。
- 生成 `BUTTERFLY_FLAP_FAST_FOLLOW_PATH_2_WING_FLAP_ONLY.blend`。
- 两个版本的路径控制器和身体在第 1、45、91 帧位置与旋转保持不变；第 45 帧渲染可见翅膀仍在拍动。

## 文件变更

- 新增仅翅膀版本构建脚本和专用验证脚本。
- 新增两个独立 `.blend`、构建报告和验证报告。
- 更新 Butterfly README，记录输出位置与动画策略。
- 生成的预览 PNG 位于本地生成目录，未作为正式资产提交。

## 验证

- 专用构建和验证通过：2 个版本均为 `ARTIST_EDIT` 默认场景，展示层仅有左右翅膀动画。
- 路径控制器和身体的采样位置/旋转静止；翅膀帧签名发生变化。
- 原有 Butterfly 全量验证通过，主文件、原 Follow Path 文件和头部摄像机副本保持有效。
- 两个来源 `.blend` 的 SHA-256 未变化；`git diff --check` 通过。

## 遗留边界

- 当前 `SOURCE_REFERENCE` 有意保留原始 Follow Path 运动；如果后续要求打开任意场景都完全没有路径运动，需要另行制作“源数据也固化”的版本。

## 待确认长期记忆
