# 2026-08-23｜Blender 材质映射与程序化草修复

- 时间：2026-08-23 00:50（北京时间）
- 类型：`bug`
- 状态：`完成`
- 目标：修复 Blender 水彩材质黑屏、补齐网页程序化草，并明确禁止构建脚本修改 Blender 用户偏好。
- 日志索引：[[日志/MOC_工作日志|工作日志 MOC]]

## 已确认的决策

- Blender 内置界面语言完全遵循用户现有安装配置；重建、验证和渲染脚本不得写入或保存用户偏好。
- 资产、对象、材质和脚本 ID 保持 ASCII 英文，中文仅用于说明文档，不把数据块本地化与 Blender 界面语言混为一谈。
- 草层必须依据旧运行时的程序化生成配置重建，不根据截图补画。

## 检查与操作

- 只读检查确认用户配置语言为简体中文，但“翻译界面”开关当前关闭；本轮没有修改该状态，也没有调用 `save_userpref`。
- 从旧 `app.js` 确认压缩运行时把紧凑映射表绑定到可见 `atlas/texture`，把带元数据的映射表绑定到 `atlas/sdf`。此前语义反置导致 Blender 材质黑屏或裁切错误。
- 修正清单语义和材质绑定后，树材质预览恢复完整水彩图像。
- 确认草不在 GLB 中，而由旧运行时按图层动态生成；解析 26 个图层的地面参数，其中 23 个启用 `hasGround`。
- 重建 23 个 `PROCEDURAL_GRASS` 网格对象，共 3141 株、50256 个三角面，保留十个草叶 atlas 区域、24 列颜色渐变、源码间距参数、风动形态键和揭示动画通道。
- `land_back_5`、`background_2` 与 `viaduc_1` 按源码保持无草，不为满足数量而擅自添加。

## 文件变更

- 更新清单提取、Blender 重建、结构验证和渲染验证脚本。
- 更新场景工作台 README、源码提取报告、渲染边界报告和媒体资源长期知识。
- 旧主文件备份到本地忽略目录 `scene_workbench/generated/backups/`，验证通过的临时文件才替换主 `.blend`。

## 测试与验证

- Blender 5.0 自动验证通过：27 个源网格、26 个可编辑水彩图层、26 个有效材质、0 个 N-Gon、0 个零面积面、编辑模式往返成功。
- 23 个程序化草对象、3141 株草叶、50256 个三角面、23 组风动通道和 23 组揭示通道全部通过。
- 生成 20 张样本图；独立树材质预览与树下草层预览均可见。
- 未修改正式网页运行时，未修改只读参考目录，未创建提交，未推送远程。
