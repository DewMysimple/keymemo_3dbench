# Blender 工作台重命名与记忆迁移

## 目标

将 `scene_workbench/` 重命名为 `blender_scenebench/`，保留整个工作台及其忽略的本地内容，并把 Blender 专属工程记忆从主线 `wiki_memory/` 迁移到工作台本地。

## 变更

- 原地移动整个工作台目录，保留 `.blend`、脚本、清单、报告、`source_snapshot/`、`generated/` 和自动备份。
- 保持 `Verminoble_Scene_Mirror_5_0.blend` 文件名以及 Blender 数据块、对象、材质和动画名称不变。
- 将 16 篇 Blender/三维场景历史日志迁移到本目录的 `日志/`，不保留主线重复副本，不改写封存日志正文。
- 新建本地 `AGENTS.md`、状态页、知识页、ADR 和独立 `memory_lint.py`；本地 MOC 负责完整 Blender 历史日志索引。
- 主线更新有效路径、任务路由和边界决策，主线 MOC 移除已迁移的 Blender 专属日志。

## Git 与任务边界

网页和 Blender 继续共用 `main`，本次不创建新的 Git 支线、仓库、子模块或 `module-replication/` 项目。网页任务写主线记忆，Blender 任务写本地记忆，混合任务分别写入两边。

## 验证

迁移后运行主线和本地记忆体检与索引、网页 lint/build、Blender 验证器和 `git diff --check`。目录深度未改变，因此 `.blend` 中指向 `public/.../xp` 的相对路径无需重写；验证器负责确认 `ARTIST_EDIT`、外部资源和场景结构保持有效。
