# 重建竖框蝴蝶轴向与干净层级

## 问题

旧竖框版本继续沿用 Master 的 FBX 空对象链与远离模型的原点，导致关系线杂乱；身体和翅膀的复合旋转也使触角方向、左右翅空间关系难以稳定控制。原 Follow Path 动画的部分帧还会让两翼发生真实表面互穿。仅旋转展示根或给原曲线增加安装角不能同时解决这些问题。

## 修复

- 保留 Master 的原生身体和双翼网格、UV、材质与贴图，重新烘焙为 `DISPLAY_Butterfly_Master_ROOT` 直接绑定身体、左翼、右翼的三对象展示层级；删除旧展示 FBX Empty。
- 展示根放在框面中心并保持世界轴对齐；身体原点重设到自身几何中心，身体沿世界 Z 轴，触角朝 `+Z`，最靠框点维持 `X=0.212`。
- 左右翅原点重设到身体两侧的解剖翅根；双翼按用户确认在框面内翻转 180°，长前翅朝上，身体方向不随之倒置。
- 两翼 Action 仅保留翅根 Z 轴曲线；保留来源帧号、手柄时间、插值、缓动与曲线节奏，分别映射到左翼 `0°～75°`、右翼 `-75°～0°`，使其只向框外折叠。
- 构建器、专用验证器和通用 `wing_flap_only` 验证器同步改为新层级与新动作契约，重复构建不会恢复旧空对象链或交叉动画。

## 验证

- 两份正式 `.blend` 均从 Master 与对应 Follow Path 来源重新构建，并在保存后重新打开验证。
- 完整检查 1–91 帧：左右翼表面互穿最大值为 `0`；左翼最大 Y 约 `-0.00275`，右翼最小 Y 约 `0.03263`，全程不换边。
- 翅根到身体的最大最近距离：左约 `0.00264`、右约 `0.00070`；没有脱节。
- 全动画最小 X 约 `0.212`，不进入正面为 `X=0.21` 的框体；框法向三维深度约 `3.4382`，不是平面贴图。
- 正视第 1、45、91 帧和第 45 帧斜视/侧视渲染通过；长前翅位于上方，触角仍朝上，闭合帧可见双翼向框外产生深度。
- `SOURCE_REFERENCE`、Master 和两个 Follow Path 来源文件的 SHA-256 未变化；所有文件图像均已打包，外部 Blender Library 数量为 0。

## 边界

- 翅膀源网格本来就是带透明贴图的薄翼面，单个完全展开帧从纯侧面会较薄；三维感来自有体积的身体、翅根铰链和动画中的向框外折叠，不通过人为加厚或替换成平面照片伪造。
