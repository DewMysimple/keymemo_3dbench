# Blender 版本管理

manifests/version_registry.json 是版本关系的事实入口。每个版本有稳定的小写短横线 ID、来源版本、目标 .blend 路径、变更集合、动画策略和状态。

当前 full 指向 blender/Verminoble_Scene_Mirror_5_0.blend。no-animation 已生成并验证，目标为 versions/no-animation/blender/Verminoble_Scene_Mirror_5_0_no_animation.blend；它在第 3586 帧固化所有非相机对象和形态键，保留三组相机动画。未来派生版本必须从 full 生成独立文件，目标文件的相对资源路径必须重新计算，并经过结构、资源和渲染验证后才能标记为可用。

版本准备工具的普通 Python 入口负责注册表检查、来源哈希、Blender 调用和版本元数据；Blender 侧资源修复脚本负责从来源打开并保存到目标，避免先打开已经失去原始相对路径基准的复制文件。
