# Blender 媒体资源与可移植性

## 资源边界

Blender 工作台的本地源镜像位于 `source_snapshot/`，生成缓存和转换资源位于 `generated/`；两者都不进入普通 Git 克隆。主 `.blend` 使用仓库跟踪的 `public/wp-content/themes/davidwhyte/resources/assets/xp/` 资源作为外部路径，Ground 图集和转换后的注释字体可以嵌入文件。

## 维护规则

- 新增或修复外部路径时，优先复用 `public/.../xp` 中已跟踪的资源。
- 不把 `source_snapshot/` 或 `generated/` 写入 `.blend` 的长期外部依赖。
- 构建和修复后使用 `tools/validate_blend.py` 检查未解析资源、路径根和嵌入资源。
- 网页侧的资源命名和公开边界见主线记忆；本页只记录 Blender 使用方式。
